# Design Patterns in Go

A collection of common software design patterns implemented in Go. This repository serves as a hands-on reference to understand how each pattern works, when to use it, and its implementation in real-world applications.

Each design pattern is organized into its own directory and contains a self-contained example with clean, readable code.

## Repository Structure

```text
design-patterns/
├── singleton/
├── factory/
├── builder/
├── strategy/
├── observer/
├── adapter/
├── decorator/
├── proxy/
├── command/
├── template/
└── ...
```

## Objectives

- Learn the intent behind each design pattern.
- Understand the problems each pattern solves.
- Explore idiomatic Go implementations.
- Build a quick reference for interview preparation and backend development.

## How to Run

Navigate to any pattern directory and execute:

```bash
go run .
```

or

```bash
go test ./...
```

(if tests are available).
